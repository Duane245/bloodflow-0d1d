# 全身脉搏波 · interactive viewer

Static page (no build step, no server): open `index.html`, or publish this folder with GitHub Pages.

- `index.html` — the viewer (canvas animation, P/Q charts, model facts). Light/dark themes follow the system;
  `?theme=light|dark`, `?t=0.14` (pause at a model time), `?v=54` (select a vessel) are supported.
- `tree_layout.js` — front-view layout of the 55 arteries (generated by `layout/build_layout.py` from the model's
  `initial_*.m` / `P6_m.m`; names from Wang 2014, Table 3.3).
- `tree_data.js` — last steady-state beat of the 55-artery run at 1 kHz (P, Q at ~20 nodes per vessel, Int16 base64;
  generated by `data/pack_viewer.py` from the MATLAB export `tree55_1khz.json`).

Model: BloodFlow (0D heart + 1D arteries + 0D terminals), https://github.com/Duane245/bloodflow-0d1d (MIT).
